# 实际谱面审稿与修订

宿主支持子 Agent 时派只读审稿者，独立读取任务、当前源码、原稿或实际 diff、匹配的编译报告与分析证据。不给编辑权限，无需另配模型服务。逐项返回位置、逐字谱片段、具体证据、通过/问题/不确定和建议；未查看范围明确列出。无子 Agent 时标为自审，不能伪称独立审稿。

逐项核对用户要求、全乐章与声部、主题变形、发展与高潮、和声/对位、终止与可演奏性。每条结论给真实谱句、具体音高/时值/声部关系及适用风格；不以作者注释证明完成。

技术失败、确定的音乐问题、尚不确定的解释和个人审美分别表达。合法现代平行和声不能套传统独立对位禁则；单个平行候选还要核实加倍、声部身份和实际同时点。

核对乐器音域、移调乐器记谱与实音、钢琴手分配和同刻跨度、速度、换气及音区平衡。轨道跨度不能直接当手跨度，MIDI不保证保留谱面声部。

ABC L:1/8 下 A2 为四分音符，A/ 为十六分音符；G,=G3/MIDI55，A,=A3/57。K:F 与 K:Dm 默认降B，D小调不默认升C。LilyPond g2 e 中 e 继承二分时值，合计4个四分拍。明确计算，避免凭字母/逗号直觉判定。

修订前后比较目标是否实现、原主题/旋律是否按要求保留、接缝是否成立及新增副作用。用户允许自主扩围；区分目标局部修改、扩围解决的问题和仍存在的全曲旧缺陷。扩围本身不是违规，但不能默默放弃保留要求。

没有可核实问题时允许不再改谱。已知问题反复未改善或预算将耗尽时保存草稿和未解决事项。

常见模型误判：C大调导音是B，不是D；单声部的属音/主音轮廓不能独自证明完整V-I和声或完满正格终止。L:1/8 下 E2 G2 c2 G2 全为四分音符，无附点。音符数一致不足以证明起音和时值一致。审稿者的术语也要回到源码核实。
